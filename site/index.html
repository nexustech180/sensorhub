Gold Var Sensor Hub

The dashboard for GOLD-VAR, an illegal-mining detection system. It shows live readings from motion, sound, vibration and distance sensors, raises alerts, and keeps a database of every reading on your device.

Install

Android

  1. Tap Download .apk on the phone. Updating from version 0.1.0? Uninstall the old app once first; later updates install over it.
  2. Open the downloaded file. If asked, allow Install unknown apps for your browser or file manager.
  3. Open Gold Var Sensor Hub. It starts in demo mode, so you see data right away.

Windows

  1. Click Download 64-bit .exe (or the 32-bit one on 32-bit Windows) and run the file.
  2. If Windows SmartScreen warns, click More info → Run anyway. The app is safe but isn't code-signed.
  3. The first start takes a few seconds while it unpacks.

Connect to the GOLD-VAR system

Sensor nodes→ radio →Arduino Mega→ESP8266→ WiFi →This app
  1. Connect your phone or PC to the same WiFi or phone hotspot as the ESP8266. If the ESP8266 can't find your WiFi, it makes its own hotspot, GOLD-VAR (password goldvar123).
  2. Read the address on the Mega's screen, page 4, for example IP: 192.168.43.120.
  3. In the app, open Settings, turn Demo mode off, enter that address under ESP32 sensor board and click Test connection.

ESP8266 gateway code

This sketch runs on the ESP8266 (ESP8266MOD / ESP-12, such as a NodeMCU or Wemos D1 mini). It passes the Mega's readings to the app over WiFi. No extra libraries are needed.

  1. In the Arduino IDE, open File → Preferences and add this to Additional boards manager URLs:
    https://arduino.esp8266.com/stable/package_esp8266com_index.json
  2. In Boards Manager, install esp8266 by ESP8266 Community.
  3. Select NodeMCU 1.0 (ESP-12E Module) (or LOLIN(WEMOS) D1 R2 & mini, or Generic ESP8266 Module) and the COM port.
  4. Copy the code below into a new sketch, type your WiFi or hotspot name and password at the top, and click Upload.
  5. Wire it to the Mega: Mega TX3 (14) → 1 kΩ/2 kΩ divider → D7, Mega RX3 (15) → D8, and GND → GND. Don't use the pins marked RX/TX.
